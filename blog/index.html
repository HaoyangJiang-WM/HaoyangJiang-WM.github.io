Are Graph Neural Networks Bound by Their Nodes?

How the same observed river network can have two different futures.

Haoyang Jiang · William & Mary · November 14, 2026

Imagine two stretches of river with identical readings at every gauge. Upstream of the first stretch, a gate opens. Upstream of the second, it stays shut. At the moment we make a forecast, the observed graphs look identical. What should a graph neural network predict?

Where does information come from?

In a message-passing GNN, each node updates its representation using messages from its neighbors. Stacking layers lets information from farther away reach a node. Every message still traces back to inputs the model received, such as node measurements, edge attributes, or a forcing variable supplied separately.

Suppose a deterministic predictor receives just the observed graph G and its current state Xt. Its forecast is

X̂t+1 = Fθ(Xt, G).

For fixed parameters, identical inputs yield the same forecast. More layers can move available information farther along the graph. The upstream gate setting is absent from those inputs.

What happens when the graph is open?

The observed graph ends at the first gauge, but the river continues upstream. An external input Bt can cross that boundary and change the observed state. The physical update now depends on Xt, G, and Bt.

Xt+1 = Φ(Xt, G, Bt).
A graph defines which nodes can exchange information, but it does not necessarily define where the information governing their dynamics originates.

A three-gauge toy experiment

All three gauges start at zero in both scenarios. At every step, each gauge keeps half its current signal and takes half from its upstream neighbor. The first gauge takes that upstream value from the boundary, which is held at zero in one scenario and at the slider value in the other.

xi(t+1) = ½ xi(t) + ½ xi−1(t),   x0(t) = B.

At gauge 2, the readings first diverge after two steps, the time it takes for the signal to cross two links. At any horizon where the two possible readings are y0 and y1, a predictor given only the common initial state must return the same value for both scenarios. For equally likely scenarios, the midpoint minimizes expected squared error, and the minimum is ( y1 − y0 )² / 4. Even the best point forecast under that loss can miss both physical outcomes.

Discussion

This ambiguity comes from the information available at forecast time. It applies to any predictor with the same inputs. Message passing makes the modeling choice especially visible because the graph is often the only path through which the physical state is represented. In the toy experiment, the boundary input is supplied by design to the simulator, while the forecast given only the initial graph sees neither scenario label.

When upstream measurements or control schedules are available, they can enter through an explicit boundary input. When earlier sensor readings contain clues about the forcing, a model can try to infer a latent boundary state from history. If two forcing scenarios remain indistinguishable even with that history, a predictive distribution can represent both futures and communicate the uncertainty.

For a hydrologic application, see Physics-Refined Spatiotemporal Forecasting on Open-Boundary Hydrologic Graphs. That work uses learned boundary proxies and physics-guided refinement for long-horizon prediction.
